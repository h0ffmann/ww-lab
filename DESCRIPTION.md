Open-source lab for ocean wave models: a 12-lesson course, runnable examples, a pinned Nix toolchain (gfortran, OpenMPI, NetCDF) with one-command regression tests, GPU benchmarks on an RTX 4090, agentic development with Claude Code, and a markdown-to-PDF pipeline that builds the course book and a research proposal in CI.
